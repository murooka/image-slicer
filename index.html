    Image Slicer の使い方

    このツールでできること

    縦に長い画像を、色が切り替わる位置で自動的に分割します。分割の位置は画面上で確認・調整してから書き出せます。

    画像はインターネット上に送信されず、すべてお使いのブラウザの中で処理されます。

    かんたん3ステップ

    1. 画像を選ぶ：左上の枠に画像をドラッグ＆ドロップするか、枠をクリックして選びます。
    2. 分割位置を確認する：右側のプレビューに赤い線で分割位置が表示されます。必要なら線を動かしたり消したりできます。
    3. 書き出す：「スライスを書き出す」を押し、ZIP でまとめて、または1枚ずつダウンロードします。

    1. 画像を選ぶ

    • JPEG・PNG・WebP など、ブラウザで表示できる画像に対応しています。
    • 縦に長い画像ほど、読み込みに時間がかかります。進み具合は左のバーに表示されます。

    2. 分割の条件を決める

    「分割条件」で、分割後の画像の大きさを指定します。値を変えると、プレビューの分割線がすぐに更新されます。

    項目意味初期値
    最小高さ分割後の画像の、高さの最小値200px
    最大高さ分割後の画像の、高さの最大値。すべての画像がこれ以下になるまで分割します1000px
    最大分割枚数分割してよい枚数の上限30枚
    • 最大高さは、最小高さの2倍以上にしてください。
    • 枚数が足りない場合などは、条件を満たせない理由が赤字で表示されます。

    分割位置の決まり方

    色が大きく切り替わる位置（背景色が変わる境目など）を優先して分割します。プレビューの右端には、「番号: 高さ」のラベルが表示されます。

    「判定の調整」では、判定の細かい重みを変えられます。通常は変更する必要はありません。

    3. 分割位置を調整する

    自動で決まった位置が意図と違うときは、プレビュー上で調整できます。

    方法A：「ここでは切らない」と指定する（条件は守ったまま）

    • 分割線をクリックすると、その付近（初期値は上下40px）が「切らない範囲」になります。条件を満たす別の位置が、自動で選び直されます。
    • 画像の上を上下にドラッグすると、その範囲を「切らない範囲」にできます。
    • 斜線で表示された範囲をクリックすると解除できます。「すべて解除」で全部消せます。
    • ほかに条件を満たす位置がない場合に限り、やむを得ず範囲内で切ります。その線はオレンジの破線で表示されます。

    方法B：分割線を直接編集する（条件より自分の指定を優先）

    • 分割線をドラッグすると移動します。
    • 分割線にカーソルを乗せて表示される × を押すと削除します。
    • 画像をダブルクリックすると、その位置に分割線を追加します。

    これらの操作を行うと「手動編集中」になります。手動編集中は、分割条件や切らない範囲は反映されません。

    • 条件を満たさない画像はラベルがオレンジ色になり、警告が表示されます。そのままでも書き出せます。
    • 「元に戻す」（Ctrl+Z／Mac は ⌘+Z）で、1操作ずつ取り消せます。
    • 「自動分割に戻す」を押すと、手動の編集を破棄して自動の分割に戻ります。

    4. 書き出す

    項目説明
    形式JPEG または PNG
    JPEG 品質0.5〜1。大きいほど高画質で、ファイルサイズも大きくなります
    1枚あたりの上限 (KB)超えた場合は、JPEG の品質を自動で下げて収めます（下限 0.5）。0 は上限なしです
    ファイル名の接頭辞例：slice_ → slice_01.jpg, slice_02.jpg …
    画像の配置先 URL入力すると、出力される HTML の画像の URL に使われます

    「スライスを書き出す」を押すと、下に結果が表示されます。

    • ファイル名をクリックすると、1枚ずつダウンロードできます。
    • 「ZIP でダウンロード」で、まとめてダウンロードできます。
    • 「HTML（img タグ）」には、分割した画像を順に並べるための HTML が表示されます。Web ページに貼り付けて使えます。

    最初からやり直す

    右上の「リセット」を押すと、画像を選ぶ前の状態に戻ります。設定も初期値に戻ります。

    アプリとして使う

    一度開けば、インターネットに接続していなくても使えます。

    • パソコンの Chrome・Edge：アドレスバーのインストールボタンからインストールできます。
    • iPhone・iPad：Safari の共有メニューから「ホーム画面に追加」を選びます。

    新しいバージョンが公開されると、画面右下に案内が出ます。
